# Локальный редактор прайсов

Запуск из корня: `desktop/facade/node_modules/electron/dist/electron.exe desktop/prices` или `pwsh -File desktop/prices/start.ps1`.

Первичная загрузка: `python desktop/prices/import_pdf.py <PDF> <private-output.json>`, затем Electron с аргументом `--price-file=<private-output.json>`. Импортёр предназначен для проверенной табличной формы этого прайса; количество строк и границы колонок требуют проверки при изменении PDF. Не является универсальным PDF/OCR импортом.

Приложение сохраняет текущий прайс и отдельные редакции в Electron userData/price-revisions. Коды, названия и единицы сохраняются из источника. Ставки — целые копейки; null означает неизвестную ставку. Импорт/экспорт редакций JSON, поиск, группировка, редактирование ставок/примечаний, включение позиций. Правила пока текстовые, автоматически не применяются. Excel-импорт, сопоставление с каталогом и расчётный модуль пока не подключены.

Фактические цены, PDF, выгрузки, история и скриншоты не публикуются в Git. В репозитории только приложение и схема. Каталожные ID пока пустые: совпадения похожих названий не подтверждают одинаковый материал. НДС и база коэффициентов ожидают подтверждения владельца.

Запуск теста схемы: `node desktop/prices/test.cjs`. Проверены все 320 исходных номеров без пропусков, уникальность кодов, выборочно многострочные названия, единицы и суммы; окно редактора и сохранение редакции проверены вручную. Шесть позиций отключены по статусу/области работ (включая покраску фурнитуры); исходные строки сохранены для просмотра.
