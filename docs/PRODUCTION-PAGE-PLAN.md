## Общие страницы: сохранить production

Существующие ID, статусы, контент и SEO не заменять. Главная 4650 использует front-page.php: новая тема меняет отображение без замены записи. Настройки Yoast, Redirection, рубрики, старые меню и пользовательские данные не импортировать.

## Порядок

1. После согласования создать новые страницы черновиками: новые ID назначает production; родителей сопоставлять по пути, не по ID dev. Переносить только шаблон, раздел/группу меню, публичный контент и проверенные SEO-поля новых страниц.
2. Проверить предпросмотр карточек, каталог, обработки, изображения, ссылки и мобильный экран. Старые /catalog/ и /product/ сохраняются.
3. Согласовать публикацию новых страниц и включение темы одним следующим этапом. Динамическое меню новой темы требует опубликованных страниц.
4. Отдельно настроить и проверить почтовую доставку; до проверки заявки выключены.

Внимание: переключение темы не откатывает страницы и БД. Для отмены новых страниц использовать созданные production ID из журнала импорта.

## Предпросмотр 2026-10-02

Новая главная проверена через штатный Customizer неактивной темы: основной экран и мобильный режим. Все img с src загрузились; один H1, canonical https://alfaglass.ru/, title «Главная – Альфа Гласс М», description присутствует. Новые ссылки требуют переноса страниц. Все 91 назначенные шаблоны найдены в установленном архиве. У 90 новых страниц пустой post_content: содержание выводится шаблонами из файлов темы; это не отсутствие описаний.

До включения: согласовать замену/скрытие заглушки фотографии производства и устранить горизонтальный сдвиг (в мобильном iframe clientWidth 305, scrollWidth 312). Причина сдвига пока не установлена. Не считать страницу полностью готовой к публикации по одной проверке первого экрана. Полный предпросмотр новых карточек на production возможен после согласованного создания черновиков.

SSH dev доступен; свободно около 4.3 ГБ. Сайты, файлы темы и БД в этой проверке не изменялись. Ветка codex/production-requests содержит origin/main и два последующих коммита на момент проверки.
