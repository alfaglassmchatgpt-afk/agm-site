# Обновление зеркал

В группе зеркал три карточки в заданном порядке: серебро, Осветлённое зеркало «Crystalvision» (Crystal), тонированные. Группа `dvuhstoronnee-zerkalo` содержит существующую страницу `materialy/zerkalo-gezella/`, переименованную в «Зеркало двухстороннее». Старый адрес сохранён. В WordPress обновлены post_title и метаполе `_agm_material_group` двух страниц. Для восстановления этих изменений нужна защищённая копия БД или ручное обновление названий и групп; SQL не публикуется.

Описание двухстороннего зеркала сверено с https://alfaglass.ru/product/zerkalo-gezella/ и сохранено для последующей редакции. Визуализация в его карточке и каталоге убрана по запросу владельца, сам файл сохранён. Точное описание и новые изображения — дальнейшая задача.

Встроенным imagegen созданы `mirror-silver-sample-v1.png` и `mirror-crystal-sample-v1.png`, рабочие копии `.local/mirror-refresh/assets/`.
