# Зеркало двухстороннее — 2026-10-02

По поручению владельца обновлена существующая карточка `/materialy/zerkalo-gezella/` и её превью в группе «Зеркала». Адрес, запись WordPress и её SEO-метаданные сохранены. Разработка и проверка выполнены сначала на dev, затем три текстовых файла и четыре новых изображения выборочно перенесены на production через файловый менеджер хостинга. БД, Yoast, редиректы, почтовая конфигурация и dev-защиты не изменялись.

Владелец согласовал изображения и описание, размещение, резервную копию и переход на официальные значения: Pilkington / NSG Group Mirropane Chrome Plus 0,1%, Chrome 2%, Chrome Spy 8%; Saint-Gobain MIRASTAR 3%. Первоначальные названия Mirostar/Mirapane и значения 0,2/5/9% не используются. Данные Pilkington в таблице приведены для 4 мм; параметры конкретной толщины и поставки уточняются. Предложение владельца: толщины 4/6/8 мм, лист 3210 × 2250 мм; это не утверждение о заводском ассортименте всех исполнений.

В общий профиль добавлены четыре исполнения и три толщины. Существующие обработки сохранены. Убрано ошибочное утверждение о невозможности закалки этого специального материала; специальные обработки требуют отдельного согласования и автоматически не включались. Галерея использует существующий `k1-variants.js`, основной блок — общий шаблон «Мой расчёт».

Новые изображения в `agm-glass/assets/generated/`:

- `two-way-mirror-sample-v1.png` — квадратный каталожный образец без численной маркировки;
- `two-way-mirror-comparison-v1.png` — сравнение 0,1/2/3/8%, художественная иллюстрация, не измерение;
- `two-way-mirror-furniture-v1.png` — мебельные фасады с выключенной и включённой подсветкой;
- `two-way-mirror-infinity-v1.png` — декоративное изделие с эффектом бесконечности.

Медиа и закрытые исходные файлы вне Git: `.local/twoway-publish`. В `agm-glass/catalog.html` заменён только блок ссылки карточки `zerkalo-gezella`: основное изображение, описание, параметры и существующая ссылка «Выбрать материал». Полный каталог не добавлялся в очищенный снимок. Для восстановления медиаматериалов и полного каталога требуется защищённая копия.

До dev-правки выполнен штатный `agm-site-backup.service`: Result=success, ExecMainStatus=0. До production-правки полные тексты трёх изменяемых файлов (`catalog.html`, `zerkalo-gezella.html`, `materials.json`) сохранены в отдельном локальном архиве восстановления; нормализованное содержимое совпало с исходными dev-файлами. Это целевая копия файлов, не новый полный бэкап production/БД. Исторические резервные копии вне штатной ротации не удалялись.
