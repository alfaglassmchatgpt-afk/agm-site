Добавлены короткие видимые тексты по назначению изделий, выбору параметров и процедуре заявки, ссылки между направлениями. Творческие H1 сохранены, предметные запросы раскрыты в H2 и тексте. Canonical не изменяли.

Проверка публичных ответов: HTTP 200, один description и правильный canonical у каждой страницы. В браузере — по одному H1; основные страницы без горизонтального переполнения на фактической ширине 320 px.
