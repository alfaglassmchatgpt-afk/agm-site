# Примеры применения K1

В карточку K1 добавлена галерея четырёх концептуальных визуализаций: ранее показанное настенное зеркало, ромбовидное панно, шесть прямоугольных элементов над изголовьем и круглое зеркало над консолью. Новые варианты имеют более светлую патину по пожеланию владельца. Указана индивидуальность рисунка каждого листа и значение образца 200 × 300 мм. Проверены загрузка четырёх изображений, галерея в браузере и сохранение конфигуратора. До правки успешно выполнен штатный бэкап с ротацией. БД и production не менялись.

Файлы темы: agm-glass/sostarennye-zerkala-k1.html и k1-examples.css. Галерея #material-examples: две колонки, одна до 760px, открытие полноразмерных изображений. Промпты: K1-EXAMPLES-PROMPTS.txt; встроенный image_gen. Размеры в промптах — ориентиры, не чертежи.

Медиа исключены из GitHub. На ВМ: agm-glass/assets/generated/k1-use-{wall,diamonds,bedroom,console}-v1.png. Локальные копии: .local/k1-examples/assets/. Для восстановления нужны защищённые медиа; они войдут в следующий плановый бэкап. Исходный референс первого примера: https://www.vashezerkalo.ru/panno-iz-antichnogo-zerkala-k1 ; изображение создано самостоятельно, это не фотография выполненного заказа.
