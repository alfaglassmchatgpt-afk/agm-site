# Группы материалов

На dev каталог `/materialy/` открывается обзором групп. Меню «Материалы» на обычном и мобильном экране содержит те же группы. Ссылка `/materialy/?group=riflenoe-steklo` открывает выбранную группу; адреса существующих страниц материалов сохранены.

Каждый материал принадлежит одной основной группе. Рифлёные тонированные и матовые варианты Moru остаются в рифлёном стекле; гладкие Bronze/Grey Satin — в тонированном. Lacobel/Matelac объединены как окрашенное стекло. Слово «рисованное» в исходном голосовом запросе предварительно интерпретировано как «рифлёное» по составу каталога; явного подтверждения пока нет.

Общая конфигурация и построение каталога: `src/themes/alfa-glass-home-2026/inc/agm-material-groups.php`. Категория определяется по slug; редактор страницы может переопределить её в блоке «Группа материала». Новая опубликованная страница раздела без известного slug попадает в «Другие материалы», пока редактор не выберет группу. Пустые группы скрыты, черновики не выводятся. Это группировка страниц темы, не WooCommerce-категории и не изменение иерархии страниц.

Поиск в обзоре ищет по всем материалам и показывает результаты с заголовками групп. Внутри группы поиск ограничен этой группой. Переходы по группам работают серверно, без JavaScript; поиск требует JavaScript. Карточки и иллюстрации берутся из существующего шаблона каталога, для новых страниц предусмотрена текстовая карточка.

Изменены выборочно пять файлов темы: новый `inc/agm-material-groups.php`, `inc/agm-navigation.php`, `page-agm-glass.php`, `agm-glass/app.js`, `agm-glass/style.css`. Исходные хеши на ВМ проверены перед переносом; полный бэкап успешно выполнен перед изменением. БД и production не изменялись. При переносе на другую ВМ сравнивать актуальные файлы и переносить только эти правки, не весь очищенный src.

Проверки: PHP lint, Node syntax check; `scripts/check-material-groups.php` через WP-CLI eval-file с `--skip-plugins --skip-themes` проверяет покрытие опубликованных страниц без дублей, выбор каждой группы и неизвестный параметр. На текущей БД: 37 материалов, 10 групп. В браузере проверены поиск «бронза» (5 результатов), сброс поиска, рифлёное стекло (10), мобильное меню и окрашенное стекло (2), отсутствие горизонтального переполнения при ширине 390px. Изображения выбранной группы загрузились. Скриншоты и данные БД в публичный репозиторий не включены.
