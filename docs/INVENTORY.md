## Защита dev

AGM_STAGING=1 и DISABLE_WP_CRON=1 проверены без чтения секретных констант. MU-плагины 000-agm-staging-guard.php и 001-agm-staging-https.php сохранены в src/mu-plugins.

В коде защиты есть блокировка WordPress HTTP API, почты, публичных форм, cron и автообновлений; noindex/nofollow; ограничение REST-записей авторизованным редактором. Apache запрещает доступ к конфигурации, cron, XML-RPC, архивам, логам и прямое выполнение PHP из wp-content; отключает почту и ряд сетевых/системных PHP-функций. CSP ограничивает загрузки и подключения своим origin. Локальные зависимости находятся в wp-content/agm-vendor (не включены в снимок).

Это проверка конфигурации, не полный аудит обходов изоляции: UFW не активен, CLI PHP не наследует все ограничения Apache.
