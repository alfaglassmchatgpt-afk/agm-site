# Регулярное обновление

После каждого значимого изменения обновляются документация и журнал по AGENTS.md.

Дополнительно 2026-09-21 создана ежедневная автоматизация в этой задаче: «ALFAGLASS: актуальность репозитория», 10:00 по локальному расписанию (Europe/Moscow). Идентификатор: alfaglass. Проверяет техническое состояние dev и обновляет безопасные сведения в GitHub только при подтверждённых изменениях. Сырые исходники, БД, медиа и персональные данные автоматически не выгружаются. Уведомления — только о значимых изменениях, новой ошибке или необходимом действии.

Автоматизация привязана к текущему приложению/задаче и не переносится командой git clone. На другом компьютере её нужно проверить или заново настроить. Для локальных проверок требуются включённый компьютер, работающее приложение, WireGuard и SSH/GitHub-доступ. Это не серверный бэкап и не GitHub Actions.

Инструкция для повторного создания: ежедневно сверять версии, активные компоненты, dev-флаги, свободное место и сертификат с инвентаризацией; публиковать только проверенные технические изменения; не трогать production, не включать интеграции и не удалять файлы; молчать при неизменном состоянии, новый блокер сообщать один раз.
