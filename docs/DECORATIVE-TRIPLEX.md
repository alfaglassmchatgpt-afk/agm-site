# Декоративный триплекс — локальный прототип, 26 октября 2026

Шаблон page-agm-triplex.php; контент agm-glass/dekorativnyy-triplex.html; scoped стили triplex.css. Предлагаемый постоянный адрес /materialy/dekorativnyy-triplex/. Production не изменён, страница WordPress пока не создана.

## Поисковые намерения

- Основное: декоративный триплекс на заказ, декоративное стекло для интерьера, Москва и МО.
- Дополнительные: крафтовый триплекс, стекло с металлической сеткой, триплекс с сеткой, рифлёный триплекс.
- Вопросы: стоимость за м², варианты состава, размеры, образцы, применение в мебели и перегородках.

Это карта содержания по исследованию выдачи и предложениям конкурентов, не отчёт частотности Wordstat и не обещание позиций. Не создавать отдельные дубли под каждый синоним. Существующие карточки MORU сохраняют адреса. Страницу фильтра craft-triplex при публикации связать с новой посадочной; решение о редиректе принимать с учётом других параметров фильтра. Canonical новой страницы должен вести на её собственный постоянный URL, не на общий каталог.

Используется agm_order_render, общий component.html, model.js и app.js, без отдельной копии логики. Добавлен профиль dekorativnyy-triplex: сетка, Silvit, индивидуальное сочетание и прозрачный состав. Локальный исходник общего конфигуратора сохраняет заявку в файл, не отправляет почту. Для публикации необходимо сравнить и использовать актуальную боевую интеграцию общего «Моего расчёта»: не заменять её этим неполным снимком. Полный materials.json не переносить: добавить только новый профиль к актуальному реестру и проверить серверную валидацию. Телефон и email в локальной шапке — безопасные заглушки очищенного снимка.

## Перед публикацией

1. Согласовать внешний вид и решение о резервировании действующего сайта.
2. Сравнить актуальные общие файлы; перенести только новый шаблон, контент, CSS, профиль и нужные медиа.
3. Создать опубликованную WordPress-страницу с постоянным URL и шаблоном; проверить один title, description, H1 и self canonical с учётом активных SEO-фильтров.
4. Обновить переход в меню и группе материалов, добавить ссылку из релевантных карточек. Проверить sitemap и доступность для индексации, отправить на переобход через доступный Вебмастер.
5. Проверить фактическую отправку полной спецификации через действующий обработчик; локальная проверка добавления в расчёт не доказывает доставку письма.
