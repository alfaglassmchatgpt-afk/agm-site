# Дихроичное стекло: прямой переход и параметры

2026-10-05. На dev и production выборочно изменены inc/agm-material-groups.php, inc/agm-configurator.php, agm-homepage/js/app.js, agm-homepage/index.html, agm-configurator/materials.json, agm-glass/dihroichnoe-steklo.html.

Промежуточный публичный экран группы заменён прямым переходом; технический ключ группы сохранён для совместимости. Старый URL группы перенаправляется 301 на материал. В каталоге карточка «Смотреть материал», возврат — «Все материалы».

В актуальном inc/agm-configurator.php условие выбора ссылки возврата изменено с `if (isset($groups[$groupKey]))` на `if (isset($groups[$groupKey]) && empty($groups[$groupKey]['direct']))`. Очищенный снимок этого файла старее действующего и не содержит блока навигации: его нельзя разворачивать поверх действующего файла.

Толщины 4/6/8 мм, лист 3210 × 2250 мм. По указанию владельца доступны все обработки обычного стекла, включая закалку, триплексование, окрашивание, а также раму и мебельный фасад. Специализированная комплектация профилем для рифлёного стекла 8 мм не добавлялась.

Использована сегодняшняя резервная копия по решению владельца. Исходные production-файлы сохранены локально вне Git. БД и Yoast не менялись.
