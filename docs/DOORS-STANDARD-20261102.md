# Двери из стекла — опубликовано 2026-11-02

## Результат

Страница `/dveri-iz-stekla/` приведена к общим шапке, навигации, теме и корзине. Использует существующие `inc/agm-aluminium-header.php`, `shared-header.css/js`, MU `agm-system-theme` и `inc/agm-quote.php`. Дополнительные аргументы helper не меняют прежние вызовы Aluminium.

Коллегин главный рендер, описание маятниковых дверей, выбор фурнитуры и условный предпросмотр материалов сохранены. Контакты не дублируются в коде страницы. Исходный контент WordPress не удалён и не изменён. Вместо собственного текста заявки используется общий список и одна контактная форма. Двери можно добавлять отдельно, редактировать и удалять; изменение параметров подтверждается кнопкой.

Статический конфигуратор фасадов получает только новые query-версии общих quote-store/quote-ui. Его прежняя локальная правка сохранения темы не входит автоматически в будущий выпуск дверей.

## Материалы и границы

- 17 материалов взяты из исходной страницы; толщина фильтруется текущим общим каталогом. Зелёное стекло не предлагает 10 мм. Estriado и Vision Sun — 8 мм.
- Некоторые существующие URL содержат историческое слово moru, хотя актуальное название материала — гладкое тонированное/матовое стекло. Ссылки сверены с текущими профилями, не переименованы по одному только slug.
- В локальный неполный materials.json синхронизированы только используемые 17 профилей из публичного production JSON. Полный production каталог содержит 85 профилей. **Не заменять его файлом из src при выпуске.**
- Сохранены исходные границы формы: ширина проёма 400–4000, высота 1000–3500 мм, шаг 1 мм. Это пределы ввода запроса, а не подтверждение допустимости конкретного полотна. Размеры, обработка, масса и комплект фурнитуры согласуются по проекту.
- Новых операций обработки и подтверждений совместимости фурнитуры эта работа не вводит.
