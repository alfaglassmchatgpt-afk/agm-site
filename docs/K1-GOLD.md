# K1 Gold

Золотое исполнение находится в существующей карточке `/materialy/sostarennye-zerkala-k1/`. Образцы и подборки примеров переключаются независимо стрелками; без JavaScript оба варианта видны подряд. Кнопки доступны с клавиатуры, название варианта объявляется через aria-live.

В конфигураторе сохранён ключ `standard` для прежних заявок, добавлен `gold`. Просмотр картинки не меняет заказ: исполнение явно выбирается в конфигураторе. Обработка и толщина одинаковы; закалка исключена.

Созданы встроенным image_gen по фотографии владельца: `k1-gold-sample-v1.png`, `k1-gold-entry-v1.png`, `k1-gold-dining-v1.png`, `k1-gold-bar-v1.png`, `k1-gold-wardrobe-v1.png`. Локальные рабочие копии — `.local/k1-gold/assets/`, на dev — каталог темы `agm-glass/assets/generated/`. Промпты: K1-GOLD-PROMPTS.txt. Медиа и исходная фотография не публикуются в Git; для восстановления нужны защищённые копии медиа, новые файлы войдут в следующий штатный полный бэкап.

Перед выборочной загрузкой HTML и materials.json сверены с ВМ. Различие materials.json до изменения было только в окончаниях строк. Штатный бэкап завершился успешно. В браузере проверены второй образец, переключение на четыре сцены Gold и подписи.
