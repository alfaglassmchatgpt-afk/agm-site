# Семантика страницы «Зеркала с подсветкой»

2026-09-28. Базовое ядро по существующему ассортименту и поисковой выдаче. Частотность в Wordstat/Google Ads не проверена; прогнозов трафика и позиций нет.

| Намерение | Запросы | Размещение |
| --- | --- | --- |
| Заказ | зеркала с подсветкой на заказ; по индивидуальным размерам; изготовление зеркал с LED-подсветкой | title, description, H1, вводный текст, производство |
| Форма | круглое, овальное, фигурное зеркало с подсветкой | заголовок галереи, существующие восемь вариантов |

| Свет | контражурная подсветка; внутренний контур; выбор цвета света | заголовки и существующие пояснения |
| Опции | зеркало с подогревом; сенсорное включение; регулировка яркости | FAQ с согласованием совместимости |
| Цена | стоимость зеркала с подсветкой; расчёт по размерам | форма задания и FAQ, без выдуманных цен |

Сохранены восемь визуализаций и существующая форма локального задания. Не добавлялись универсальные обещания влагозащиты, наличия, сроков, гарантии, минимальной цены или достаточности подсветки для всего помещения. Изменения только на dev после штатного бэкапа и проверки хэшей двух исходных файлов. Контакты в публичном снимке остались обезличенными; живые файлы изменялись точечно.

Подход: полезные тексты вместо списков ключей, уникальные заголовок и описание, один H1. Источники: [Google SEO Starter Guide](https://developers.google.com/search/docs/fundamentals/seo-starter-guide), [Яндекс: заголовок и описание](https://yandex.ru/support/webmaster/ru/search-results/title-and-description).

Dev noindex сохранён. Выход на production требует отдельного поручения; после публикации нужны проверка canonical, sitemap, индексируемости и уточнение запросов по данным поисковых систем.
