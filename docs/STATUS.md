# Состояние проекта

Дата: 2026-09-21.

- ВМ доступна через существующие SSH/WireGuard. Apache и MySQL активны.
- Доверие к dev-сертификату установлено на текущем Windows-компьютере; главная HTTPS проверена браузером.
- Владелец подтвердил успешный вход в dev-админку во встроенном браузере.
- Подготовлен публичный базовый снимок активной темы, собственных плагинов, dev-конфигурации и инструкций. Это неполный, очищенный снимок для сопровождения, не полный бэкап сайта.
- Боевой сайт, БД и код на dev не изменялись в ходе инвентаризации.
- Срочно требуется решить нехватку диска: около 391 МБ свободно, 99% занято. Ничего автоматически не удалено.
- Следующая инфраструктурная задача: защищённая внешняя копия БД и медиа с проверкой восстановления. Место хранения и политика пока не определены.
- В исходной теме есть встроенные настройки интеграций. Публикуемая копия очищена; перенос интеграций в закрытую конфигурацию работающего сайта — отдельное изменение.
- Проверена главная dev и конфигурация защит; полная функциональная проверка редактора/форм, сети и восстановление сайта пока не выполнялись.

После каждого значимого изменения обновлять этот файл и CHANGELOG.md. Регулярная проверка должна публиковать только проверенные технические сведения; данные пользователей и необработанный код автоматически не выгружать.
