## Что было не закончено

- Абстрактные названия («Панорама», «Круг · мягкий ореол»), каталог после информационного раздела.
- Изображение открывалось отдельно от страницы; не было фильтра по форме.
- На публичной странице форма описывала тестовый TXT-экспорт без отправки менеджеру. Исходный app.js также прекращал работу при стандартной шапке, включая обработчики самой формы.
- Общий расчёт не подключён в шаблоне LED; параметры и контакты не объединены с общей заявкой.

## Локальные изменения

- Сохранены существующие изображения, шрифт и общая цветовая система. Каталог из восьми решений сразу после hero, три колонки на десктопе, две на планшете, одна на телефоне.
- Названия по форме и подсветке; фильтр, увеличение в диалоге, возврат фокуса, reduced-motion.
- Настройка зеркала сразу после каталога: выбранное изображение, размеры, количество, свет, управление, пожелания. Для круга только диаметр. Целые положительные миллиметры; максимальные производственные размеры не выдуманы и требуют согласования.
- LED adapter использует существующий AGMQuoteStore/AGMQuoteReady, тип mirror, data.led. Общая отправка и хранение не дублируются. Сохраняются все опции, редактирование по id; локальная отправка остаётся тестовой без почты.
- Убрана декоративная нумерация; добавлены применение и FAQ. Цены, гарантия, IP, мощность и сроки не выдуманы.
- Обновлён description в исходном макете. При публикации проверить итоговый title/description/canonical Yoast, чтобы не было конкурирующих метатегов; URL сохранить.

## Переходы и дальнейшее наполнение

С главной уже есть переходы из меню/карточки: это не страница без входящих ссылок.
Рекомендуемые дополнительные переходы после согласования макета:

- Каталог обычных зеркал: «Нужна подсветка?» рядом с переходом к зеркалам в раме.
- Душевые: «Подобрать зеркало с подсветкой для ванной» в связанных изделиях.
- Зеркала в раме: сравнение с вариантом без рамы с LED.
- Комплексные поставки: зеркала для гостиниц и салонов, только в релевантном разделе.

Переходы с этих страниц пока не изменены. В текущем макете предусмотрены обратные контекстные ссылки. /catalog/ при проверке вернул 404; использован существующий /#products, как в живом меню.

Следующий полезный контент: фотографии выполненных работ с разрешением на публикацию, подтверждённая комплектация, технические пределы размеров, условия гарантии и монтажа. Добавлять Product/Offer с выдуманной ценой или отзывами нельзя. FAQ полезен посетителю независимо от показа расширенного сниппета.
