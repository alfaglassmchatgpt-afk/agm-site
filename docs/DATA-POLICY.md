# Публикация данных

Репозиторий публичный по разрешению владельца. Публикуются только сведения об архитектуре и очищенные исходники. Не публикуются персональные данные, секреты и необработанные выгрузки.

В оригинальных файлах найдены встроенные параметры SMTP и Google Sheets. В снимке SMTP-поля очищены, Google Sheets использует getenv с пустым значением по умолчанию. Рабочие оригиналы на dev и production не изменены. Перед включением интеграций владелец должен отдельно проверить актуальность и при необходимости сменить эти доступы, храня их вне темы.

Контактные email и телефоны в снимке заменены заглушками; встроенный блок команды удалён; файлы с персональным контентом о компании и медиа исключены. Список исключённых текстовых файлов — source-exclusions.json. Полный список опубликованного кода с SHA-256 — source-manifest.json. Другие неактивные темы и сторонние плагины представлены версиями в инвентаризации.

scripts/prepare-source.ps1 формирует снимок из локального .local, но требует ручного просмотра результата. scripts/check-public-content.ps1 проверяет известные шаблоны и запрещённые типы; она не заменяет проверку смысла текста, фотографий или внешних ссылок. Не автоматизировать отправку произвольных файлов с ВМ в GitHub.

Локальный .local содержит необработанный материал для проверки и исключён из Git. Не пересылать и не архивировать его для публикации. Резервирование приватного содержимого допускается только в защищённое хранилище владельца.
