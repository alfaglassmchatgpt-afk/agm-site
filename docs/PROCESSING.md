# Обзор обработки стекла и зеркал

Dev-адрес: `/obrabotka-stekla-i-zerkal/`. Запись page ID 5175, шаблон `page-agm-processing.php`. Это справочная страница, не товар; конфигуратор на неё не устанавливается.

12 разделов соответствуют operations.json: cut, shape, polish, grind, bevel, drill, sandblast, temper, laminate, paint, film, frame. Названия и SVG-иконки читаются из общего реестра. Текст описывает общий принцип, не заявляет модели станков или наличие конкретного оборудования. Схемы кромки условные; фотографии производства не добавлены.

Проверочная техническая ссылка: [AGC FIX-IN, раздел Cutting and drilling](https://www.agc-yourglass.com/sites/default/files/2024-04/IG_FIX-IN_V15_EN.pdf), ограничения обработки после закалки. Операции и ограничения по материалам основаны на согласованном реестре проекта.

`inc/agm-processing.php` добавляет обычную ссылку через wp_footer в нижней части страниц. Верхнее меню не меняется. `inc/agm-configurator.php` передаёт processingUrl; app.js добавляет ссылку на соответствующий якорь в подсказку операции. Контент обзорной страницы рендерится сервером, доступен без JavaScript. Новый шаблон включён в существующее оформление redesign через inc/agm-homepage.php. На dev запрет индексации сохраняется; публикация на production — отдельное задание.

Для восстановления создать WordPress-страницу с указанным slug и назначить шаблон. Существующую страницу с таким адресом сначала проверить. БД не хранится в публичном репозитории; требуется защищённый бэкап. Код переносить выборочно после сравнения с актуальной темой. Резервная копия перед изменением успешна; новая запись войдёт в следующий штатный бэкап.

Проверки: PHP lint, синтаксис JS, тесты общей модели; 12 разделов в браузере, отображение страницы, ссылка подсказки на #bevel, ссылка внизу страницы. Публичный сканер и ручной просмотр изменений перед коммитом.
