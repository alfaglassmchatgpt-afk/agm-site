# Crystalvision — описание и применение

Обновлена только dev-карточка `/materialy/zerkalo-osvetlyonnoe/`.

Краткое описание услуг (индивидуальные размеры, формы, кромка, замер, доставка, монтаж) подготовлено по [боевой карточке](https://alfaglass.ru/product/zerkalo-osvetlyonnoe/). Формулировки о геометрии уточнены: осветлённая основа улучшает нейтральность цвета, но не заменяет ровное полотно и правильный монтаж. Толщины 4/6 мм подтверждены владельцем ранее. Формат листа и наличие согласуются с менеджером.

Профиль `agm-configurator/materials.json`: вариант standard = Crystalvision (Crystal); толщины 4/6, девять операций как у серебра, без закалки. Существующий общий конфигуратор выводит иконки и обработку по этому профилю.

Пять сцен встроенного image_gen используют существующий образец `mirror-crystal-sample-v1.png` как ориентир нейтрального материала. В галерее каждая отмечена «ВИЗУАЛИЗАЦИЯ», общее пояснение отличает их от фотографий заказов. Для полноразмерного просмотра предусмотрена ссылка на изображение. Промпты: [CRYSTAL-PROMPTS.txt](CRYSTAL-PROMPTS.txt).

Медиа исключены из публичного репозитория. Копии в рабочей папке `.local/crystal-interiors/assets/` и на dev в теме `agm-glass/assets/generated/`. Для восстановления на другом компьютере нужен защищённый бэкап с медиа; очищенный src не является полной копией сайта.
