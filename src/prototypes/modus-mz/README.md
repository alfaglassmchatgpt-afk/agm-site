# MODUS MZ — автономный прототип

Согласованный локальный эксперимент; не часть production-темы. Нет отправки заявок, почты, интеграций или хранения персональных данных. Для будущей интеграции использовать общий «Мой расчёт», не создавать отдельную корзину.

Установка: Node.js, `npm install` (подготавливает локальный vendor), затем статический HTTP-сервер только на 127.0.0.1 в этой папке. Проверки: `npm test`. Three.js 0.180.0, лицензия MIT копируется в vendor. Vendor и node_modules исключены из Git. Открывать через HTTP, не file://.

## Основания и пределы

Официальный источник: https://modusline.ru/site/files/1/fasadnye-profili-1.pdf, печатные страницы 63–66; раздел https://modusline.ru/catalog/fasadnye-profili-modus/seriya-mz. Сверено 14.10.2026. PDF и изображения производителя в репозиторий не включаются.

Девять рамочных профилей: MZ 01/02/04/07/09/10/12/13/17. MZ 13-01 — дополнительный профиль-ручка, не самостоятельная рамка. Наполнение 4 мм, минимальный фасад 200 × 200 мм. Максимальные размеры показаны как рекомендации высота × ширина, а не подтверждённые пределы конкретного заказа. Для MZ 04 список цветов ограничен пересечением PDF и текущей карточки (без шампани/коньяка); наличие не проверяется.

Сечения реконструированы по странице 64: внешние контуры, полости, выступы, пазы. `sections.js` задаёт общий источник геометрии для 2D и 3D. Режим «Профиль» показывает отрезок 90 мм с открытым торцом. Рамка собирается из экструзий с соединениями 45°; центральный участок стороны с ручкой заменяется на MZ 13-01. Габариты — каталожные, непроставленные стенки (обычно принято 1,2 мм), рёбра и радиусы — оценочные. Местоположение стекла в пазу — визуальная реконструкция без моделирования клея/уплотнителя. Это не производственный CAD и не присадка. Петли условные.

На странице 65 приведена обработка под сборочные уголки, её нельзя применять как координаты петель. Тип петли и допустимость нагрузки необходимо согласовать; число петель не выводится делением веса на 4 кг. Отступы 100 мм, предупреждения 60/80 мм — демонстрационные значения, не нормы MODUS. Геометрия стекла вычисляется по каталожному вычету из наружных габаритов. Оптика и экранные цвета приблизительные, не образцы реального материала.

Экспорт JSON — описание пожеланий с предупреждениями, не заказ и не чертёж для изготовления. В дальнейшем нужны проверенные CAD-сечения, точные петли/присадки и согласование технических ограничений с производством. Ссылку на официальный каталог можно показывать в информационном разделе; перепубликация PDF не выполнена.

## Каталог стекла и визуализация

`glass-catalog.json` — безопасный снимок общего каталога от 14.10.2026: 39 материалов, 49 вариантов с подтверждённой толщиной 4 мм. Неуказанные толщины исключены, наличие не проверяется. Это не отдельная производственная логика: будущая интеграция должна использовать общий каталог и «Мой расчёт». Снимок обновляется при изменении общего каталога; тест проверяет допустимость каждой позиции.

Для зеркал используется плоское отражение тестовой студии; для стекла — приближённые пропускание света и матовость. Переключаемые блоки за стеклом служат только тестовым фоном. Рельеф задаётся в миллиметрах: Krezet 2 мм и Raywall 90T 100/14 мм по замерам владельца, MORU Ultra матовое около 12 мм по сохранённой карточке. Остальные неподтверждённые фактуры явно отмечены и пока не воспроизведены. На общем виде мелкий рельеф может сглаживаться; точная оптика требует отдельной калибровки по образцам. JSON содержит slug, вариант, толщину, дату снимка и ограничения визуализации.

Для MZ 13/13-01 добавлено визуальное смягчение углов сечения (отступ до 0,18 мм, ограничен длиной соседних сегментов), без изменения каталожного габарита. Радиус не подтверждён производителем. Материал профилей использует процедурную продольную карту шероховатости; окрашенные покрытия отделены от металла. Это экранная имитация отделки, не физически измеренные покрытия.

Браш A25/A29: собственные карты цвета/шероховатости/микрорельефа и анизотропный блик. Визуальные ориентиры — https://modusline.ru/catalog/fasadnye-profili-modus/seriya-mz/fasadnyj-profil-13.html и её образцы покрытий (242 × 120 px). Они не включены в исходники. Масштаб рисок оценочный; после сверки с фото владельца карта 256 × 256 повторяется через 20 мм поперёк и 60 мм вдоль профиля, с нерегулярными прерываниями рисок. ACES применяется ко всей 3D-сцене.

По фото образцов 20 × 60 мм также добавлена продольная фактура A00 и A21. A00 не отождествляется с A29. Фотографии не включены в репозиторий; глубина рисок и точный цвет по ним не измерены.
