# Локальный Aluminium

Не публиковать каталог автоматически. Запустить `prepare.mjs` после подготовки vendor в соседнем modus-mz: используются та же версия Three.js и тот же glass-catalog.json, отдельный ассортимент не поддерживается. Результаты подготовки и изображения не коммитить. Рабочая копия .local/aluminium-catalog обслуживается на 127.0.0.1:8785.

Т-911 — модель компоновки, не производственный расчёт. Сечения, торцы, материал и глубина путей условные; приводы и ремень не моделируются. Без нижнего рельса, с условными направляющими роликами. Заявки, сохранение в общий «Мой расчёт» и уточнение интерьера — следующие этапы интеграции. Формулы: официальный каталог MODUS sistemy-mezhkomnatnyh-peregorodok.pdf, печатные стр.115–120. Тест: node --test t911.test.mjs.

Материалы используют общий glass-render.js из modus-mz: prepare.mjs копирует его вместе с glass-groups.js. Параметр unitScale=.001 переводит оптические расстояния в метры, размеры текстур передаются в мм. Квартира создана геометрией Three.js, без внешних картинок и клиентских фото.

Оболочка site-shell.css использует цветовые токены основной темы; site-shell.js управляет только локальной темой. prepare.mjs подготавливает также фирменные SVG-логотипы. Шапка адаптирована для прототипа, без подключения боевых форм/трекеров. Перед публикацией заменить localhost-ссылки на существующий конфигуратор и согласовать подключение общих сервисных элементов. Публикация — после просмотра владельцем и новой защищённой резервной копии.
