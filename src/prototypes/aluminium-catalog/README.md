# Локальный Aluminium

Не публиковать каталог автоматически. Запустить `prepare.mjs` после подготовки vendor в соседнем modus-mz: используются та же версия Three.js и тот же glass-catalog.json, отдельный ассортимент не поддерживается. Результаты подготовки и изображения не коммитить. Рабочая копия .local/aluminium-catalog обслуживается на 127.0.0.1:8785.

Т-911 — модель компоновки, не производственный расчёт. Сечения, торцы, материал и глубина путей условные; приводы и ремень не моделируются. Без нижнего рельса, с условными направляющими роликами. Заявки, сохранение в общий «Мой расчёт» и точная визуализация материалов — следующие этапы интеграции. Формулы: официальный каталог MODUS sistemy-mezhkomnatnyh-peregorodok.pdf, печатные стр.115–120. Тест: node --test t911.test.mjs.
