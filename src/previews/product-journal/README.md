# Локальный журнал изделий
Исходники автономного макета. Рабочий комплект находится в .local/product-journal.
Медиа assets/editorial-grid.png сохранено в локальном комплекте, бинарные медиа исключены из публичного снимка.
Встроенный imagegen создал шесть интерьерных сцен в сетке 3 × 2. Условия промпта: architectural editorial photography, warm ivory limestone and walnut, glass shelves, frameless mirror, glass tabletop, bronze bevelled mirror tile wall, UV bonded display cover, bathroom glass shelf. No people, no logos, equal square cells.
Пять сцен показаны в журнале через CSS. Ссылки открывают существующие материалы с общим «Мой расчёт».
Проверены синтаксис JavaScript, пять разворотов в браузере, границы перелистывания и возврат по оглавлению. Мобильные жесты требуют отдельной проверки.
