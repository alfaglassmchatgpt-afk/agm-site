# ALFAGLASS — проект сайта

Публичный репозиторий сопровождения https://alfaglass.ru и его изолированной dev-копии. Инвентаризация: 21 сентября 2026 года.

**Начать работу с другого компьютера:** [docs/HANDOVER.md](docs/HANDOVER.md).

Здесь сохранены инвентаризация, конфигурация Apache для dev, защитные MU-плагины и очищенный текстовый снимок активной темы и двух собственных плагинов. Снимок **не является готовым пакетом развертывания**: персональный контент, медиа, часть сторонних ресурсов и параметры интеграций исключены. Не копировать `src` поверх работающего сайта целиком.

Публичность не означает предоставление лицензии на фирменные материалы; лицензии стороннего кода сохраняются в его файлах.
